# 大模型技术知识库

## LoRA 低秩微调
LoRA（Low-Rank Adaptation）是一种参数高效微调技术。它的核心思想是：冻结原始模型的全部权重，在模型旁路添加两个低秩矩阵，只训练这两个小矩阵。这样需要更新的参数只占全部参数的极小比例（通常 0.1%~1%），大大降低了显存占用和训练成本。QLoRA 在 LoRA 基础上进一步把基座模型量化为 4bit，让 7B 模型也能在单张消费级显卡上微调。

## RAG 检索增强生成
RAG（Retrieval-Augmented Generation）通过"先检索、后生成"的方式，让大模型基于外部文档回答。流程包括文档加载、文本切分、向量化、向量检索、重排、最终生成。它主要解决大模型知识截止过期、私有数据无法利用、以及幻觉问题。常见的优化手段有混合检索、重排（Reranker）、上下文压缩等。

## Transformer 自注意力机制
Transformer 架构的核心是自注意力（Self-Attention），它让每个词在编码时都能关注句中所有其他词，从而捕捉长距离依赖。注意力通过 Query、Key、Value 三个矩阵计算：Query 与 Key 点积得到注意力权重，再与 Value 加权求和。多头注意力（Multi-Head Attention）让模型从不同子空间学习不同关系。

## 向量数据库
向量数据库（Vector Database）专门用于存储和检索高维向量。它通过 ANN（近似最近邻）算法，在海量向量中快速找到与查询向量最相似的向量。常见的有 FAISS、Chroma、Milvus、Pinecone、Qdrant。在 RAG 中，文档被切分后用嵌入模型转为向量存入向量库，查询时用相似度（如余弦相似度）检索最相关内容。

## Prompt 提示词工程
Prompt Engineering 是通过设计输入指令来引导大模型输出的技术。常用技巧包括：角色设定（Role Prompting）、少样本示例（Few-shot）、思维链（Chain-of-Thought）、结构化输出约束（JSON Schema）等。好的 Prompt 能显著提升回答的准确性和格式规范性。

## Agent 智能体
Agent（智能体）是能自主完成多步任务的大模型系统。它通常具备三个能力：规划（Planning）、工具调用（Function Calling / Tool Use）、记忆（Memory）。通过循环执行"思考→调用工具→观察结果→再思考"的流程，Agent 可以完成检索、写代码、调用 API 等复杂任务。LangGraph、AutoGen 是常用的 Agent 编排框架。

## 模型量化
量化（Quantization）是把模型权重从高精度（如 FP16）压缩到低精度（如 INT8、INT4），以减小显存占用和加速推理。常见的量化方法有 GPTQ、AWQ、GGUF。量化会带来少量精度损失，但对 7B 以下的模型影响通常可接受。4bit 量化可以把 7B 模型从约 14GB 显存压缩到约 4GB。

## 模型蒸馏
知识蒸馏（Knowledge Distillation）是用一个大模型（教师）的输出指导训练一个小模型（学生），让小模型尽量复现大模型的能力。它常用于把 70B 级别的强模型压缩成 7B 甚至更小的模型，在保持大部分能力的同时大幅降低推理成本。

## Function Calling 工具调用
Function Calling 是大模型的一种能力：当模型判断需要外部信息或执行动作时，它会输出一个结构化的函数调用请求，而不是直接生成文本。应用层收到这个请求后执行对应的工具（如搜索引擎、数据库查询、代码执行），再把结果返回给模型继续生成。这是构建 Agent 的核心机制之一。

## 评估指标 Hit@K 与 Recall
在检索评估中，Hit@K 表示"返回的前 K 个结果中是否包含正确答案"的命中率；Recall@K 表示正确答案被召回的比率。它们衡量检索器能否把相关文档找出来。结合 MRR（倒数排名）和 NDCG（归一化折损累积增益）可以更全面评估排序质量。
